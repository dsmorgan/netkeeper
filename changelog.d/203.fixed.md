Enrichment reads what the first live run could not (#203). A website that points at LinkedIn itself no longer makes a visit unreadable: the overlay's links go through `/safety/go`, which is now unwrapped; a link to the member's own profile is skipped, and any other LinkedIn page is kept as a website. The location reads from the top card, which renders the degree twice, and is logged once per visit. Experience entries read their title from the plain paragraph it renders in. A `contact-instant-message` section is ignored quietly, since the CRM has no field for it. A website is kept only when it is an absolute http or https url; the CRM refuses a link with any other scheme from every source, and the contact page shows such a stored link as plain text rather than a link. An experience entry whose title element holds no text of its own is skipped rather than read with its fields shifted.
