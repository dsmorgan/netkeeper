FastAPI application factory: `netkeeper serve` runs the API under `/api/v1` (`health`, `me`, the `events` SSE stream, and a `tasks/ping` diagnostic showing that routes enqueue work and answer `202`), migrates the database and creates the local user at startup, refuses state-changing requests that lack `X-Netkeeper-Client: 1` or come from another origin, discovers API modules automatically, and serves the built frontend. `netkeeper openapi export` writes the schema that `make gen-client` turns into the TypeScript client.
