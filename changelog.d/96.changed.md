Auto-tag rules can now be edited and reordered on the Tags and rules tab. Edit opens the rule in place, with the same live match count as a new rule, and saving changes the rule rather than replacing it, so it keeps its place and its credit for the tags it already added. Move up and Move down set the order, which decides which rule gets the credit when two rules for the same tag match. The LinkedIn-archive export now says that it leaves out contacts with nothing identifying in its columns, as nine-column already did, and the export dialog's count says when the chosen preset may write fewer rows than it counts. A pattern the schema refuses no longer shows pydantic's "Value error, " prefix.
