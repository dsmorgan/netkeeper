Scheduled LinkedIn inbox polls now stop after two polls in a row end `route_changed` or `not_found` (or the page can't be read at all), which means the messaging page changed shape. While this inbox breaker is tripped, `netkeeper serve` skips each scheduled inbox poll as `inbox_route_changed_breaker`; connections syncs and enrichment are unaffected, and the connections breakers never skip an inbox poll. A run you start by hand is still allowed, and `netkeeper linkedin inbox` that completes clears the breaker; `netkeeper linkedin schedule reset-breaker` clears it too. `netkeeper posture`, the Settings page's Posture section, `netkeeper linkedin schedule status`, and the top bar's background checks show it. While it is tripped nothing refreshes the inbox, so the existing inbox hold keeps LinkedIn steps for watched contacts waiting once the inbox is stale; the posture warning says so while that applies. `reset-breaker` clears only the count; the hold lifts when a poll completes.
