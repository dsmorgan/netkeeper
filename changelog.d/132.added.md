Importing a LinkedIn archive now records an import run, so it shows in the import history with every file's counts and its connection rows, and can be rolled back from its run page or with `netkeeper import rollback` like a CSV import: the contacts it created and the message and invitation interactions it wrote are deleted, and contacts it only enriched get their earlier values back. The archive result screen links to the run, and `netkeeper import archive` prints its id.
