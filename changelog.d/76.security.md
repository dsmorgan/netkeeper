CSV exports have an opt-in "Safe to open in a spreadsheet" setting (`spreadsheet_safe=true` on `GET /exports`, `--spreadsheet-safe` on `netkeeper export`). It puts a `'` before any cell that starts with `=`, `+`, `-`, `@`, a tab, or a carriage return, so a profile field crafted as a formula shows as text in Excel, Sheets, or LibreOffice instead of running. The setting is off by default because it changes the file: a spreadsheet-safe CSV no longer re-imports cleanly, and `+1…` phone numbers gain a leading quote too.
