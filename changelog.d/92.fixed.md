Four legibility and feedback fixes on the triage screen. A message body that is only an inline image no longer renders its markup as visible text: the raw-string fallback is now only for a parse that produced neither text nor elements, which is the truncated tag it was written for, and a body with nothing readable in it says so instead of claiming none was stored. Notes go through the same plain-text pass, keeping the line breaks they were typed with, so markup pasted into a note is text rather than markup. A decision key pressed before the next contact has arrived now says it did nothing instead of vanishing — six presses against a slow backend used to decide two and drop four in silence. And a decision whose write is refused now says the contact stays as they were and will be served again on reload, and leaves them in the run's trail, marked, so `←` reaches them for another go.
