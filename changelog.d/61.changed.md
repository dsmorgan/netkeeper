Merging two contacts now carries the merged-away contact's tags and tag suppressions to the survivor instead of dropping them with the row (#61). Tags are deduplicated per tag with `tag_contact`'s precedence: a `manual` assignment beats a `rule` or `llm` one, a tie keeps the survivor's row, and a `rule` assignment that moves keeps its rule credit so the next auto-tag run does not count it as newly added. A suppression on either contact carries over and beats the other's automatic assignment in both directions, so a tag you deliberately removed from either person stays off the survivor and no later run puts it back.
