The import wizard (P1-21) takes the downloaded LinkedIn zip with no extraction step: dropping or choosing it, or a lone `messages.csv` or `Invitations.csv`, goes straight to `POST /imports/archive` with an explicit Import step and a result screen naming what each file contributed (connections, messages, invitations) and which files were left unread. `Connections.csv` on its own keeps going through the existing CSV mapping and candidate-review screens. A new panel explains how to request the export from LinkedIn, that it arrives by email within 1 to 24 hours, and which file to pick by hand for someone who already extracted one. Each of the archive endpoint's 422s gets a plain-language explanation alongside the backend's own message.
