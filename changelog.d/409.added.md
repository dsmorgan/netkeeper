A **Check now** button asks netkeeper to check Gmail for replies at the next campaign tick, within a minute, instead of waiting out the reply-poll interval. You find it in the background-checks popover and beside a campaign's "replies checked" line. The button never reads Gmail itself: the tick runs the poll with the same arming, mailbox checks and read budget as every other poll, and pressing it again before that tick doesn't add a second poll. It's refused, with the reason, when `netkeeper serve` isn't running, no mailbox is armed or connected, or every armed mailbox needs you to sign in again. If the check still hasn't run three minutes later, the button comes back and says so.
