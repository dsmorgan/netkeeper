`make chrome` (`scripts/chrome.sh`) starts the netkeeper Chrome profile with its debugging port. It waits until the port answers, and it clears a profile lock that a crashed Chrome left behind. `make reset` (`scripts/reset-data.sh`) archives the database into `<data dir>/archives/`, which is never pruned, and then removes it, so the next `serve` starts fresh. `--restore` puts an archived database back. netkeeper itself still never starts a browser: you run these scripts by hand.
