The contact page has a Met control with Met, Not met, and Clear (back to untriaged). It writes through the same function the Triage keys use, so `met_source` is `manual`, `triaged_at` is set (or cleared), and the change is an undoable decision. Triage has a "Jump to a contact" search over the queue being served: pick a contact to triage them next without deciding the ones before them, and the queue carries on in its normal order afterwards. A new `GET /triage/contacts/{contact_id}` returns one contact's card when the queue being served holds them.
