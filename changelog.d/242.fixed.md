Rolling back an import whose contacts have since been sent a campaign message is refused with a reason (`409 created_contacts_messaged`), with or without force, instead of failing with a server error: a sent message is never deleted. A contact's campaign enrollments now count among the things a rollback would lose, so deleting them needs force.
Checking contacts for enrollment reads the campaign's recency window and first step fresh, so a change another session saved is never missed.
