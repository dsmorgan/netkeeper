A Gmail client for campaigns: drafts, send, threads, labels, reply history and message search, over Google's API client. Every call logs what it is for, never a message, an address or a token. When Gmail refuses the mailbox's token during a campaign's call, the mailbox is marked "needs re-authorizing" and email steps pause, as a failed token check does. An in-memory fake with the same interface, which threads follow-ups the way Gmail does, backs the engine's tests; one test against your own account runs only when you ask for it ([docs/gmail-setup.md](docs/gmail-setup.md)).
