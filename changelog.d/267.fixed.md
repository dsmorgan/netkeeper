A campaign email can no longer be sent twice when the connection to Gmail drops after the message is sent and before Gmail answers: the send is reported as "outcome unknown" instead of being sent again silently.

A Gmail quota refusal that names only its status (`RESOURCE_EXHAUSTED`) is now treated as a rate limit rather than a refused token, so it no longer marks the mailbox "needs re-authorizing". The mailbox card and banner now explain the `insufficientPermissions` and `http_403` reasons instead of showing Google's raw code.

A reply from Gmail that is cut short is now reported as a temporary failure (with the outcome unknown for a send) instead of an unexpected error, and the Gmail connection no longer follows redirects, so a redirect can never resend a message.
