Enrichment now reads each profile from what LinkedIn's own page loads: it opens and scrolls the profile, clicks **Contact info** once (only on the one Contact info link of a profile whose id matches the contact's), and reads the details the page fetches in answer, sending no request of its own; the in-page API fetch it used before is removed. A profile or overlay netkeeper cannot read writes nothing and counts toward the run's unreadable limit, and `netkeeper rehearse` now rehearses this pattern, click included.
