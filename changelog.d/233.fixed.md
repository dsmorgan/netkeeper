A tag rule's pattern is now also refused when an alternation inside an unbounded repeat has branches that could match from the same place, as in `(a|aa)+`, `(a?|a)+` or `(\w+\s+|and\s+)+`: these split text as many ways as a nested `+`, so they can backtrack for seconds or minutes. Alternatives that start differently, or that differ by a later character such as `((senior|staff|lead)\s+)+`, are still accepted.
