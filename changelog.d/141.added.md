Triage can make a tag. Type a name nothing matches in the `t` picker and it offers to make it and put it on, without leaving the run — the tag somebody thinks of while looking at a contact is never a rule, and going away to create it lost both the run and the thought. What it makes is a manual tag, which is what the batches read as evidence you know somebody.

A "retired" default rule ships with the others, and it is the one default that reads the company as well as the title and the headline: "Retired" is as often the employer as the job. It matches `retired`, `retiree` and `retiring` but never `retirement`, which is the word in the titles of people who work in retirement planning.

Defaults are now recorded by name rather than by a single "seeded" flag, so a default added later reaches a database that was set up before it existed. A default you deleted still stays deleted.
