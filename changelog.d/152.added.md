`BrowserRun.scroll(plan)` replays a `pacing.ScrollPlan` on a run's own tab: one `mouse.wheel` per step, sleeping each step's pause and then the final dwell, and returning the page actually scrolled (reopened first if the user had closed it, the same recovery every other in-page call gets). `PageLike` stays exactly as narrow as it was -- the mouse is a slice `BrowserRun` borrows locally, not a widening of the shared protocol -- and the sleep is an injectable callable so offline tests take zero real time, with an optional `cancelled` callback polled before each wheel event and again before the dwell. `netkeeper.linkedin.rehearse` now replays its own scroll step through this method instead of a second, separate implementation, so the existing smoke test that watches a real page scroll (`test_the_rehearsal_scrolls_the_real_page`) now exercises `BrowserRun.scroll` against a real Chrome.
