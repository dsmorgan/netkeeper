Rolling back an import no longer deletes a contact the import created after a sync or another source filled in more about them (a LinkedIn URN, a headline, a location). The rollback is refused and counts those contacts as "another source filled in since"; rolling back with force still deletes them.

An archive zip whose file names are marked as UTF-8 but are not is refused as `damaged` with a message that says so, rather than one claiming the names no longer match their files.
