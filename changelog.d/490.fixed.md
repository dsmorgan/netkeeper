The prefill no longer refuses the Message click when the page styles the link's first letter with `::first-letter`. Chrome's hit test answers with that pseudo-element, which the click's check couldn't tie to the link, so it read the link as covered. The check now reads each pseudo-element's host and counts the link's own first letter, or one inside it, as the link. Another element's first letter over the link still covers it. `message-check` labels such a hit as a pseudo-element, inside the control or covering it, instead of as inside a shadow root.
