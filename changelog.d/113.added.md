Triage starts from what netkeeper already decided (spec 10.2, #64). The auto-tag rules now run as part of an import — the archive importer and a CSV run's commit — over the contacts it created or enriched and no others, inside the same transaction, so an address book is tagged the moment it lands and a failed import takes its tags with it; the counts are in the archive report, on the `import_runs` row (`tagged_contacts`, `tags_added`, `tags_removed`), and in the commit's response. The suggestion catalogue grows past the single message-history batch: an invitation that carried a personal note either way with no thread since; one batch per tag the user has given a meaning (`tags.met_signal`, `met` or `not_met`, set through `POST`/`PATCH /api/v1/tags`); and, offered last, everyone there is no evidence about at all — no interaction of any kind, no tag with a meaning, and nobody you have met or written to at their company. The message batch no longer counts a bare invitation as a conversation: the archive stores one as an `li_in`/`li_out` row like a message, and clicking Connect is not message history. Every batch can be read before it is taken (`GET /api/v1/triage/suggestions/{key}/contacts`, paged, from the same query the apply uses), still refuses with `409` when the set has moved since the count it showed, and is still undone in one step. A decision netkeeper makes is never mistaken for one made by hand: migration `0008` adds `contacts.met_source` (`manual` or `automatic`), `triage_decisions.reason` (the key of the suggestion a batch came from) and the `bulk_not_met` kind, and `tags.met_signal`. `GET /api/v1/triage/next?decided_by=automatic` is the review pass, serving exactly the contacts a batch decided on the same cards with the same keys; deciding one by hand makes it `manual` and takes it out of that queue, and undo puts it back. `progress.automatic` counts what is waiting there. Against the reference archive: 616 contacts tagged during the import with no button press, 171 offered as met from message history, 257 as not met with no evidence, and 430 of 616 decided automatically, all of them reviewable.
