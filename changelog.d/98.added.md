`netkeeper.linkedin.voyager` (spec 9.3): the header builder for LinkedIn's in-page Voyager API (`csrf-token` from the `JSESSIONID` cookie, `x-restli-protocol-version`), endpoint path/query/`decorationId` constants for connections pages, contact info, profile details, and conversations, and a defensive parser for each — a shape a parser does not recognize raises `RouteChanged`, never `KeyError`. The fetch helper itself is deferred to a small follow-up once P2-01's browser provider lands; this module defines the `VoyagerFetch` protocol it will satisfy. Fixtures are hand-built and sanitized, with the capture-and-sanitize procedure documented in the module.
