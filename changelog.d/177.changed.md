Cancelling an enrichment run now interrupts the scroll on the profile it is visiting, including the dwell at the end and the scroll back to the top before the Contact info click, instead of waiting for the visit to finish. The dwell is checked every second; the pauses between wheel events, the pointer-rest walk, and the last slice are not. The short pause before the Contact info click still cannot be cancelled: a cancel that arrives there still clicks. A cancelled run does not read, click, or save the profile it was scrolling. A checkpoint or login wall the tab lands on during the scroll still ends the run with that wall, even when a cancel arrives too.
