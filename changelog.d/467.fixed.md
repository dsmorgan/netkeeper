With two data directories sharing one database through `NETKEEPER_DATABASE_URL`, one directory no longer marks the other's live LinkedIn run `failed` and starts a second run on the same Chrome. A live run now refreshes a heartbeat on its row (`sync_runs.heartbeat_at`, migration 0041) every 20 seconds. A run counts as left behind only when its heartbeat (or, without one, its start) is two minutes old and no browser lock you can see is held. A run whose process really stopped is still recovered two minutes after its last heartbeat.
