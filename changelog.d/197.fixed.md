A connections sync no longer fails when Chrome can't return the body of one of the page's pagination answers. netkeeper logs the cause as a class name and a fixed category, and keeps scrolling so the page can ask again. If the page moves past that answer, or doesn't ask again within six scrolls, the run stops as an incomplete `answer_lost` run. The run's note names the start index. Nothing is aged, and the stop doesn't count toward the route-changed breaker. A run that fails inside its runner is now recorded only once.
