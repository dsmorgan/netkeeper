Database core: a SQLite engine with WAL and foreign keys on (`NETKEEPER_DATABASE_URL` overrides the location), `session_scope()`, the `UTCDateTime` column type, Alembic wired to the models with the first migration (`users`, `settings_kv`), a migration diff test that also runs on PostgreSQL when `NETKEEPER_TEST_DATABASE_URL` is set, and `netkeeper db upgrade|current|revision`. `db upgrade` creates the local user on first start.
