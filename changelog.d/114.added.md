Triage now has on-screen controls, a position, a visible queue, and a way back (P1-23). Every key in the map has a button beside the card printing its key, so the map can be learned by using the screen rather than by reading the help overlay; both paths go through the same handler, and fifty contacts still take fifty requests and no waiting between cards, on the mouse as on the keyboard. The card carries its position — which contact of this run, and how much of the queue is left — and a queue panel lists the contacts already passed with the decision each carries, the one on screen, and the ones already in hand; any of the passed can be opened. `←` walks back through them: it is a cursor over the run, not an undo, so it sends no request, writes nothing, and leaves the undo stack where it was, and the card says which decision the contact already holds. Deciding from there replaces that decision and steps forward, so `← m` puts you back where you were. `u` keeps its meaning, "take back the newest write", and the screen says in one line what each of them just did.
