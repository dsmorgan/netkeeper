`netkeeper linkedin message-check <contact id> --bubble` no longer fails when the bubble's close button holds an icon. The name read asked Playwright for the text of every `aria-hidden` part, and Playwright refuses that on an `svg`. The read now skips a part with no text, and skips the text-without-hidden-parts name when a part isn't HTML but holds text. The same read serves the prefill's recipient check and auto-send's close control. When the check fails, the report now names the step that failed (finding tabs, reading dialogs, reading the composer, or reading the close control) and the kind of failure (timeout, target or tab closed, invalid selector, strict mode violation, or not an HTML element), in fixed words only.
