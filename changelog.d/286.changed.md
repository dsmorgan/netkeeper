The dashboard's **Changed jobs** card now lists the position changes netkeeper noticed during enrichment, dated by when it noticed them, instead of the start and end dates on the profile, which people often fill in late. A new headline or location alone does not count, and neither does an import. Migration 0028 adds `contact_snapshots.position_changed`; snapshots written before it count as no change, so the card fills as enrichment notices new moves. The `last_position_change` template merge field still reads the profile's dates. The **Budget and heat** card now says when the weekly cap is what limits today's profile visits, for example "Weekly cap reached (300 of 300)."
