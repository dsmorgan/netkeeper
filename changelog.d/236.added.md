The Templates page is now a working editor (P3-10). Lint runs as you type, through the new read-only `POST /api/v1/templates/lint`, so errors show before you save. Each error shows its line number when lint gives one, and refused constructs read plainly, for example "Loops aren't supported in templates". You can pick a contact through the contact search and preview a saved version for them. The subject and body show as plain text, and a field with no value renders empty with a warning. The version history lists every version and opens an older one read-only. When an edit to a template a campaign uses is saved as a new version, the page says so.
