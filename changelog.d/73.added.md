Filters can ask who is in a list. `list_member` compiles now: a static list becomes a subquery over its membership rows, and a smart list's own filter is folded into the one you are writing, so a list can be built out of another list. Membership means what the list page shows — an archived or merged-away contact is not a member, and a list belonging to someone else, or one that has since been deleted, matches nobody rather than breaking the filter. No list can be made to define another in a circle, or to pull in more lists than the compiler will expand: the save that would do it is refused, and says which list it would have broken. If one ever does end up unreadable, the lists page still lists every list, marking that one rather than failing.
