An invitation is no longer counted as a message on the triage card. The importer stores one as the same kind of row, so a contact whose whole history was a single "LinkedIn invitation" read "1 message" over a card whose only line said otherwise — while the batches, which have always excluded invitations, left that contact out of the message batch. Both now ask the same question, and the card says how many invitations are on file beside the messages.
