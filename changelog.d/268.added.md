A mailbox card on the dashboard (CP5, spec 10.1): the connected Gmail address, whether it is connected, needs re-authorizing, or disconnected, and when its token was last refreshed, with a link to Settings — or **Re-authorize** when Google needs it again. With no mailbox ever connected, it points to Gmail setup instead. It reads `GET /api/v1/mailboxes`, never `/status`, so it still shows while the Keychain is locked (#256 item 5), and refreshes on the `mailbox.status` server event without a reload, the same as the re-auth banner it mirrors.
