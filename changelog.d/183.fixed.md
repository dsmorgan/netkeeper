`scripts/chrome.sh` no longer mistakes a reused pid for the netkeeper Chrome: a profile lock's pid must now actually have the profile open (not just be alive and Chrome-named), and a `--type=` helper process is never treated as a holder. A Chrome holding the profile on a different debugging port gets an accurate message instead of "without the debugging port", and detection found only through the lock file now names it. `--json` is parsed without a sibling `python` (a `uv tool`/pipx install's `netkeeper` is a symlink with none next to it), and the resolved port is validated as numeric.

`scripts/reset-data.sh` now moves a created-but-unverified archive aside as `.failed` instead of leaving it in `archives/`; `--list` orders a same-second collision (`-1` after the bare name) by when each was actually written; and a benign `lsof` WARNING (a stale network mount) no longer blocks a reset when nothing holds the database.
