User scoping (ADR 0005): `netkeeper.scoping` provides `scoped()`, `scoped_update()`, `scoped_delete()`, `get_scoped()`, and the explicit `unscoped()` escape hatch for queries against user-owned tables, plus a runtime guard, installed on the app's session factory and the test fixtures, that raises `UnscopedQueryError` for any select, update, or delete touching a user-owned table without the helper, and for a new user-owned row with no `user_id`. `settings_kv` gains `get_setting`, `set_setting`, and `delete_setting`. The test suite gains the two-user isolation harness (`tests/isolation/`), which discovers every list endpoint in the OpenAPI schema and fails when one is not registered. `set_setting` is a single `INSERT ... ON CONFLICT DO UPDATE` on SQLite and PostgreSQL, and SQLite connections now wait up to five seconds for a busy database instead of failing at once.
