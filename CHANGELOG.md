# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) once it has releases.

Unreleased changes live as fragments in `changelog.d/` (one file per change, `<issue>.<type>.md`, or `+<slug>.<type>.md` without an issue) and are assembled into this file at release time with `towncrier build`. Preview with `make changelog-draft`.
